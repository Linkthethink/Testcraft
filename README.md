https://test-craft-1e937fdd.base44.app/


## Purpose of the product
TestCraft is a powerful and intuitive tool designed to streamline the creation, management, and visualization of software test cases.The site is developed by AI vibe coding platform, Base44.  Whether you're testing e-commerce flows or brainstorming decision logic. 
QA engineers and developers not only generate and manage test scenarios with ease, but also remind them to create information validation and critical error checking points when building products.


## Features
### 1. Test Case Generator
Automatically generate structured test cases based on input parameters, logic rules, or decision models. Ideal for reducing manual effort and ensuring comprehensive test coverage.Common UI fields includes: Drop-down List, Radio Button, Checkbox, Text Field, Numeric Input, Date Picker.

### 2. Shopping Cart Test Generator
Specialized module for generating test cases tailored to shopping cart workflows, including:
•Add/remove items
•Quantity updates
•Discount applications
•Checkout validations

Usually, e-commerce operation staff needs to test cart with popular product skus. The products are saved and can be reused next time.

### 3. Decision Tree Path Generator
Visualize and generate all possible paths through a decision tree. Useful for:
•Business logic testing
•Rule-based systems
•Complex conditional flows

Users save decision tree with customized tag name so that they can retrieve back the result.

### 4. Saved Decision Trees
Save and manage your decision trees for reuse, versioning, or collaboration. Easily load and edit trees to adapt to evolving requirements.

### 5. Test Results Viewer
View and analyze test execution results in a clean, organized interface. Supports:
•Pass/fail summaries
•Detailed logs
•Filtering and sorting
